# @zerobias-org/schema-microsoft-azure-azureresourcegraph

Product schema for `microsoft.azure.azureresourcegraph` (Azure Resource Graph).
Mirrors the `amazon.aws.rexplorer` schema shape: extends-only classes, no
declared properties — inventory semantics come from the Azure suite schema
(`@zerobias-org/schema-microsoft-azure`) and the zerobias base schema.
